# LXP와 산림 공공데이터 사례의 근거

정리일: 2026-09-15. 본인이 제공한 업무 설명, 제출 자료의 검수표 이미지, 로컬 저장소에서 확인한 일부 커밋 이력을 구분해 기록한다. 업무 전체의 성과를 독립적으로 재검증한 문서는 아니다.

## LXP

### 담당 범위

본인이 제공한 커밋 기반 업무 정리에 따라 LMS 핵심 기능의 풀스택 개발과 공개 홈페이지 UX/UI 개선으로 범위를 보완했다. 시험과 평가, 설문, 알림, 이수 관리, 역할별 대시보드, AI 학습지원, 공개 사이트 탐색 흐름 및 반응형 UI를 포함한다. 전체 플랫폼을 혼자 구축했다고 표현하지 않는다.

기존 계약 표기는 2026.07~2026.10 (진행중)으로 유지한다. 이번에 제공된 2026.07.27~2026.09.15는 구현 이력 범위로 구분하며 완료일로 해석하지 않는다.

### 추가 확인한 이력

로컬 LXP 저장소의 2026.07.27~2026.09.15 비병합 커밋 목록에서 다음 이력을 확인했다.

| 커밋 | 커밋 메시지에서 확인한 작업 |
| --- | --- |
| `826e4ab` | 학생 프로젝트 37개 통합 및 교육/취업 페이지 브랜드 정리 |
| `51e5342` | 수료생 인터뷰 27건 내부 상세 이전 |
| `d599ceb` | 수료생 인터뷰 27건 페이지 추가 |
| `5440b32` | 취업캠퍼스 커리어 문 열기 인터랙션 구현 |
| `e48ddee` | 취업캠퍼스 여명 이미지와 빛/구름 인터랙션 적용 |

37건과 27건은 본인 설명과 커밋 메시지가 일치하는 콘텐츠 통합 규모다. 이번 작업에서 현재 배포 데이터의 개수를 새로 집계하거나 상담 전환율, 사용자 만족도, 운영 시간 절감 효과를 측정하지 않았다. 전체 커밋의 작성자와 변경 내용을 전수 감사한 것도 아니다.

본인이 제시한 337개 커밋 수와 히어로 시안 10개는 대표 성과 수치로 추가하지 않았다. 로컬 시안 모음의 존재는 확인했지만 원본 공개 범위가 정해지지 않아 포트폴리오 저장소에 복사하거나 배포하지 않았다. 현재 남아 있는 도메인 문제는 해결 성과로 적지 않는다.

기존 AI 영역 테스트의 범위는 [측정 결과](project-behavior-measurements.md)를 따른다. AI 단위 테스트 결과를 새로 추가한 전체 LMS 기능과 공개 홈페이지의 검증 결과로 확대하지 않는다.

## Forest

### 신규 데이터 발굴과 검수

본인은 신규 개방 대상 데이터 **10건 이상이 검수에서 인정받은 건수**라고 확인했다. 정확한 전체 합계는 확인하기 어려우므로 10건 이상으로 표기한다.

첨부된 검수표 이미지에서는 국립산림과학원의 다음 4개 자료와 각 행의 ‘인정’ 표시를 확인했다.

1. 분비나무 봉화군 현지외보존원 모니터링(2년차)
2. 2025년도 구상나무 복원시험지(금원산, 월봉산) 모니터링
3. 산림치유효과 현장데이터(2025년도)
4. 연료 수분함량 일반화 자료 및 예측모델 고도화 자료

전체 10건 이상의 인정은 본인 확인에 따른 것이며, 이미지에서 10건 전체를 확인했다는 의미는 아니다. 이미지의 원문 URL은 길고 줄바꿈돼 있어 추측해 복원하거나 링크로 게시하지 않았다.

### 담수용 사방댐 데이터 개선 제안

두 번째 이미지에서 활동 당시 제출한 문제점, 개선 아이디어, 검수결과 ‘인정’을 확인했다.

| 진단한 문제 | 제출한 개선 아이디어 |
| --- | --- |
| 등록 43건, 완공 연도 2003~2012년으로 이후 준공분 미반영 | 2013년 이후 준공분을 포함한 전국 단위 갱신 및 갱신주기 명시 |
| 좌표계 표기 부재, 소수점 자릿수 5~12자리 혼재 | 좌표계 메타데이터 기재 및 자릿수 통일 |
| 관리기관의 지역 표기 단위 혼재 | 시도와 시군 컬럼 분리 |
| 접근 조건, 수심, 동절기 결빙 등 이용 정보 부재 | 헬기 담수 판단에 필요한 접근 조건과 계절별 이용 가능성 항목 추가 |

43건과 연도 범위는 당시 제안서의 진단 대상 상태다. 현재 공공데이터포털의 최신 상태를 조회한 결과가 아니다. 좌표계 기재는 개선 제안이며 원본 좌표계가 WGS84임을 검증한 것은 아니다.

검수 인정은 제안의 검수 결과다. 데이터 개방 완료, 실제 원본 수정, 현장 적용, 산불 대응 성과까지 확인된 것으로 표현하지 않는다. 첨부 이미지 원본 자체는 이번 배포에 포함하지 않았다.
